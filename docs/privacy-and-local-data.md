# 隐私与本地数据说明

最后更新：2026-07-31

## 1. 当前版本的数据边界

Arcana Web 与“星简集”微信小程序当前不提供账号、手机号、支付或 AI 解读接口，不采集定位、通讯录、相册内容，也不做跨设备同步。

用户填写的问题、卡牌结果与历史记录只保存在当前设备本地。应用不会将问题或卡牌记录上传到 CloudBase。

## 2. 本地存储清单

| 存储键                          | 内容                         | 用途                         | 清理入口           |
| ------------------------------- | ---------------------------- | ---------------------------- | ------------------ |
| `arcana-single-reading-history` | 最近的卡牌记录、牌阵与版本号 | 查看、恢复和删除历史记录     | 关于与隐私说明弹层 |
| `arcana-daily-card`             | 日期、cardId、正逆位与时间   | 保证同一天返回同一张今日一牌 | 关于与隐私说明弹层 |

“清空全部本地记录”只删除以上两个应用自有键，不调用全局 `clearStorage`，避免影响其他数据。

## 3. 网络与 CloudBase

- Web 牌面从应用本地静态资源读取。
- 微信小程序牌面从 CloudBase 云存储按需读取，并转换为临时 HTTPS 地址。
- CloudBase 图片请求只携带牌面文件 ID，不包含用户问题、抽牌结果或历史记录。
- 原创牌背在小程序主包中以内联资源提供。

## 4. 分享

分享仅在用户主动点击时触发，由浏览器或微信平台完成。应用不读取联系人。

微信好友转发与朋友圈分享代码已接入；最终真机闭环等待备案通过后验证。

## 5. 用户侧入口

页面底部提供“关于星简集 · 隐私说明”或“关于Arcana · 隐私说明”入口，展示：

- 数据使用范围；
- CloudBase 图片用途；
- 分享边界；
- 内容免责声明；
- 清空全部本地记录入口及二次确认。

## 6. 自动验证

- 本地数据清理测试覆盖两个应用自有键和部分失败反馈。
- 微信文案门禁继续排除审核高风险词。
- TypeScript、ESLint、H5 与微信生产构建必须通过。
- 微信构建产物必须保留“星简集”品牌和隐私入口。
